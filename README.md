# Shiki Futon

A static concept website for a Japanese-inspired futon mat. Open `index.html` locally or publish this folder with GitHub Pages.

The ₹500 production cost and ₹2,500 price are classroom assumptions, not verified commercial quotes. Product images are inspiration images, not photographs of a finished Shiki Futon.
